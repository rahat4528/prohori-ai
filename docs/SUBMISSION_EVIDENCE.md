## 2. External Network Egress Audit

A strict audit of all network communication pathways across the codebase reveals:

1. **Default Mode (Local / Offline)**:
   - Zero outbound requests to external internet IPs or third-party hostnames.
   - Fonts are 100% bundled locally in `web/public/fonts/` (zero Google CDN egress).
   - Knowledge base is 100% bundled in local Python data structures (zero NVD/MITRE API egress).
   - Telemetry streams locally over `127.0.0.1` and `localhost`.

2. **Optional Cloud LLM Mode (Only if explicitly enabled via environment variables)**:
   - `https://generativelanguage.googleapis.com` (Google Gemini REST API — if `GEMINI_API_KEY` is provided)
   - `https://api.groq.com` (Groq Cloud API — if `GROQ_API_KEY` is provided)
